# My Cloud Landing Zone

Welcome to the documentation for my cloud landing zone — the platform that
provisions and manages GitHub organisations, Google Cloud, and Terraform
Cloud from YAML.

Start with the [design overview](DESIGN.md), read the binding
[standards](STANDARDS.md) before proposing anything structural, and follow
the [bootstrap procedure](https://github.com/elliott-farrall/ef-mgt-devops/blob/main/bootstrap/GUIDE.md) for first bring-up.
